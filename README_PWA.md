# 学級名簿メーカー PWA版について

「学級名簿メーカー」は、先生の学級名簿づくりや提出物チェック表作成を支援する無料アプリです。v0.7.0からPWA（Progressive Web App）に対応し、ブラウザから独立したアプリのようにインストールして利用できるようになりました。

## PWA版の特徴

- **インストール可能**：パソコンのブラウザから「アプリとしてインストール」することで、デスクトップやスタートメニューからすぐに起動できます。
- **オフライン対応**：一度開いた後は、インターネット接続がない環境（オフライン）でも主要な機能を利用できます。
- **端末内保存**：入力した児童のデータは外部サーバーへ送信されることはありません。すべてお使いの端末内（ブラウザの保存領域）に保存されます。

## インストール方法

1. Google Chrome、Microsoft Edgeなどのブラウザで「学級名簿メーカー」のWeb版にアクセスします。
2. 画面内に表示される「**アプリとして追加**」ボタンをクリックします。（表示されない場合は、ブラウザのアドレスバー右端にあるインストールアイコンや、メニューの「アプリをインストール」から追加できます）
3. インストールが完了すると、専用のウィンドウでアプリが開きます。

## データ保存とプライバシーについて

- **データは外部送信されません**。
- 名簿データは使用中のブラウザ（端末）に自動保存されますが、**ブラウザの履歴やキャッシュを削除するとデータが消える**ことがあります。大切な名簿は必ず「**JSON保存**」機能を使ってファイルとして手元に保存してください。
- **共有パソコンでの注意**：他の先生と共有で使っているパソコンの場合、作業後に「保存データを削除する」などの対応を行い、個人情報の保護にご注意ください。各学校・自治体の情報セキュリティ・個人情報取り扱いルールに従ってご利用ください。

## Windows版exeとの違い

これまでのWindows版（exeファイル）は引き続きご利用いただけます。
PWA版はブラウザから直接インストールして利用できるため、新バージョンの自動通知などのメリットがあります。
学校のPC設定でexeファイルが使えない場合はPWA版を、逆にブラウザのローカル保存が制限されている場合はポータブルexe版をご活用ください。
